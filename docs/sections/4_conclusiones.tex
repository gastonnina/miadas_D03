\chapter{Conclusiones}

\section{Conclusiones}

La propuesta del sistema plantea una alternativa más flexible que la búsqueda textual exacta para localizar convocatorias relevantes dentro del SICOES. La integración de embeddings, PostgreSQL con pgvector y LangChain establece una base técnica sólida para una solución reproducible y extensible.

\section{Aportes}

Entre los principales aportes esperados se encuentran la organización de un pipeline reproducible de datos, la definición de una línea base SQL comparable, y la construcción de un marco académico para evaluar recuperación semántica aplicada a contrataciones públicas.

\section{Trabajo futuro}

Como líneas futuras se consideran la incorporación de documentos adicionales de ficha, el enriquecimiento del corpus con PDFs, la experimentación con modelos de embeddings alternativos y la evaluación de estrategias híbridas más avanzadas.
